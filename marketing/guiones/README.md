# Guiones de video

Los escribe el agente `guionista`. Todos siguen el mismo formato, para que cualquiera pueda grabarlos.

## Formato

- **Vertical 9:16** (1080×1920). Se publica el mismo video en TikTok, Reels y Shorts.
- **Duración:** 10–30 segundos para redes y 45–60 para tráileres.
- **Gancho en los primeros 2 segundos:** una pregunta, un desafío o algo raro en pantalla. Si no engancha ahí, el resto no importa.
- **Texto en pantalla siempre:** mucha gente mira sin sonido. Que el video se entienda muteado.
- **Voz en off (VO):** opcional. Si se graba, en rioplatense y con onda de mesa de truco; si no, el texto en pantalla la reemplaza.
- **Cierre:** el link (en la bio) y una pregunta para que comenten.
- **Material:** el banco de clips ([banco-de-clips.md](banco-de-clips.md)). Cada guion dice qué clips usa.

## Plantilla

```markdown
# NN · Título
- **Objetivo:** qué tiene que lograr (alcance, clics, comentarios)
- **Pilar:** leyendas / IA / con amigos / desafíos / detrás de escena / costumbres
- **Duración:** X s · **Público:** ...
- **Clips:** C01, C07...

| Tiempo | Imagen | Texto en pantalla | VO / sonido |
|---|---|---|---|

**Caption:** ...
**Hashtags:** ...
**Variante para testear:** otro gancho para el mismo video
```
